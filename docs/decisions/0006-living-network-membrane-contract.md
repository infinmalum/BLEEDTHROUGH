# ADR 0006：Living 网络膜墙接口契约

状态：已接受（2026-09-14）

- Regenerative Membrane 是 Artery 的本地受液端。每 250 mB Hematic 恰好转为一格既有营养；手动 Nutrient Paste 输入继续有效，不改变原配方或上限。
- Artery 仍只向自身朝向的相邻 BlockEntity 尝试一次固定上限转移。它不会发现、缓存或遍历网络，也不持有区块、世界或实体引用。
- 膜墙的未转换 Hematic 缓冲和营养均为夹紧的持久标量。拆除、断连、卸载或重启不生成或丢失 Artery 端的流体；膜墙销毁时只移除其自身状态。
- Hematic Actuator 继续作为第二个可见耗液用途。8.7 不加入全局网络求解、自动分流、外部 Mod 接口或新的无限生长规则。

## 验证

- 自动验证 250 mB 转换、序列化、断连守恒，以及既有膜墙保护与愈合回归。
- 真实玩家布局、长时间卸载／重启、循环网络、平衡和正式资产保留 `[~]`。
