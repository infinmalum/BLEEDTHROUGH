# ADR 0005：Hematic 基础回路契约

状态：已接受（2026-09-13）

- `meatscape:heart_pump` 保持既有 ID 和 Raw Tissue→Collagen 行为；每次成功加工额外生成固定、可持久化且有容量上限的 Hematic 流体量。
- Artery 只向自身朝向的相邻节点转移每 tick 最多 50 mB；不扫描、缓存或保持网络／区块引用。Actuator 每 tick 最多消耗 10 mB，并在成功消耗时输出红石信号。
- 每个节点只保存已夹紧的标量 mB 数值；转移一次完成且总量守恒。拆接、卸载、重启和循环不会创建流体；旧 Heart Pump 没有数据时默认空槽。
- 本阶段不实现桶、世界流体方块、Create／IE 转换或全网络求解；它们必须在后续独立契约中扩展。
